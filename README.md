# Project Manager Mastery Path

A free, structured, module-wise project management training program —
entry level to master level, with real frameworks, templates, and worked
examples in every module, and a hands-on deliverable at the end of each
level. Not a coding track: this is charters, schedules, risk registers,
RACI charts, EVM reports, and governance models.

**Live site:** https://sigilipelli.github.io/project-manager-mastery-path/

## Contents

- **Level 1 · Entry** — what PM is, project lifecycle, scope/schedule/budget/risk/stakeholder basics, communication plans, tools overview, full charter + schedule project
- **Level 2 · Intermediate** — agile PM, advanced scheduling, EVM basics, deeper risk/procurement/quality, change & team management, agile sprint plan project
- **Level 3 · Advanced** — program & portfolio management, advanced risk/vendor management, PMO fundamentals, scaling agile, project recovery, program plan project
- **Level 4 · Master** — leading PMOs, enterprise portfolio management, digital transformation, crisis leadership, executive governance, full program charter capstone

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
